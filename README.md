# 🐾 AmiPet

Aplicação web desenvolvida para facilitar a adoção responsável de animais, conectando pessoas interessadas em adotar com pets que procuram um novo lar. O projeto oferece uma interface moderna, intuitiva e responsiva para tornar o processo de adoção mais simples e acessível.

🔗 **Repositório:** https://github.com/Andre-StudioNerd/Amipet

## 📖 Sobre o Projeto

O **AmiPet** é um projeto Front-End criado para incentivar a adoção responsável de cães e gatos. A aplicação apresenta informações sobre os animais disponíveis para adoção, permitindo uma navegação simples e agradável, com foco na experiência do usuário e em boas práticas de desenvolvimento.

## ✨ Funcionalidades

- Listagem de animais disponíveis para adoção
- Visualização dos detalhes de cada pet
- Busca e navegação intuitiva
- Interface moderna e responsiva
- Componentes reutilizáveis
- Design voltado para uma boa experiência do usuário

## 🛠️ Tecnologias Utilizadas

- React
- JavaScript
- HTML5
- CSS3
- Vite
- Node.js

## 🚀 Como Executar

Clone o repositório:

```bash
git clone https://github.com/Andre-StudioNerd/Amipet.git
```

Acesse a pasta do projeto:

```bash
cd Amipet
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
